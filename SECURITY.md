# Security policy

Please **don't report vulnerabilities in public issues or pull requests.**

Report them privately through GitHub:
[Security → Report a vulnerability](https://github.com/gemstack-rb/gemstack/security/advisories/new).
Include what's affected, how to reproduce it, and the impact you see. We'll
acknowledge the report, keep you updated, and credit you in the release notes
unless you'd rather not be named.

Security fixes are released for the latest version.
