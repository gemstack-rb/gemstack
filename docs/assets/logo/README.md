# GemStack logo

| File | Use |
|---|---|
| `gemstack-logo.svg` / `gemstack-logo-dark.svg` | Mark + name, for light / dark backgrounds (README, docs, slides) |
| `gemstack-mark.svg` / `gemstack-mark-dark.svg` | The mark alone, for light / dark backgrounds |
| `gemstack-avatar.svg`, `gemstack-avatar.png` (512 px) | Square icon: GitHub organisation avatar, favicon, social profiles |

Colours: ruby `#e11d48` (facets `#fb5a78`, `#be123c`, `#9f1239`, `#881337`), slate
`#0f172a` / `#334155` on light backgrounds and `#e2e8f0` / `#94a3b8` on dark ones.

The name is set in the system UI font, so it can look slightly different on
each platform. Outline it (convert the text to paths) in the final version.
